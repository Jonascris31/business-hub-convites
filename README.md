# Business Hub — Convites Digitais

> Landing page comercial para divulgação e venda de convites digitais interativos e personalizados.

🌐 **Produção:** https://convites.businesshubsaas.com.br/

---

## 📌 Sobre o projeto

O **Business Hub — Convites Digitais** é uma solução comercial desenvolvida para oferecer convites digitais interativos para diferentes tipos de eventos.

A proposta vai além de um convite tradicional em imagem: o convidado acessa uma experiência digital responsiva diretamente pelo celular, com informações do evento, elementos interativos e integração com canais de comunicação.

Este projeto também faz parte do ecossistema **Business Hub**, utilizado como exemplo de desenvolvimento de produtos e soluções digitais personalizadas.

---

## 🎯 Objetivo

O projeto possui dois objetivos principais:

1. Oferecer uma solução comercial acessível para pessoas que desejam convites digitais personalizados.
2. Demonstrar a capacidade do Business Hub de criar e disponibilizar soluções digitais completas para clientes e pequenos negócios.

A landing page foi desenvolvida para funcionar como um canal de aquisição de clientes, apresentando a solução, seus benefícios, planos e uma chamada direta para atendimento pelo WhatsApp.

---

## ✨ Principais funcionalidades

### 💌 Convites digitais

- Convites personalizados
- Layout adaptado ao evento
- Experiência otimizada para dispositivos móveis
- Link exclusivo para compartilhamento
- Compartilhamento através do WhatsApp e redes sociais

### 🎨 Experiência interativa

- Animações e transições
- Elementos interativos
- Demonstração do convite diretamente na landing page
- Apresentação visual dos recursos disponíveis

### 📍 Recursos para eventos

Dependendo do projeto contratado, o convite pode incluir:

- 📅 Data e horário do evento
- 📍 Localização
- 🎵 Música
- 📸 Galeria de fotos
- ⏱️ Contagem regressiva
- ✅ Confirmação de presença (RSVP)
- 💬 Integração com WhatsApp

## 📱 Experiência mobile

O projeto foi pensado principalmente para dispositivos móveis, considerando que o principal canal de compartilhamento dos convites é o WhatsApp.

A interface utiliza:

- Layout responsivo
- Elementos adaptados para telas pequenas
- Botões de ação de fácil acesso
- Navegação simplificada
- Chamada direta para atendimento
